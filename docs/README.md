# NORPC Replica Analysis

This repository contains an interactive technical review of Replica-based
trip characteristics being developed for the New Orleans Regional Planning
Commission (NORPC) travel demand model.

## View the Analysis

The interactive analysis is available through GitHub Pages:

**https://cachow827.github.io/norpc-replica-analysis/**

The site is intended to support review of current regional travel patterns
and development of travel inputs and benchmarks for SELATRAM v10.

## About the Analysis

In the absence of up-to-date regional household travel survey data, Replica
provides an additional source for understanding current travel patterns in
the NORPC region. The analysis uses Replica Fall 2024 weekday trip and person
data and focuses on trips made by NORPC residents with both trip ends within
the study area.

The review includes:

-   Preparation of Replica trip and person data for the NORPC analysis area;
-   Development of model-facing trip classifications based on the TRMG2 trip
    type framework;
-   Comparison of combined and detailed trip purpose definitions;
-   Trip generation summaries by purpose;
-   Trip distance and travel time distributions;
-   Mode share summaries; and
-   Departure time distributions and peak-hour patterns.

The interactive site allows the results to be reviewed using either combined
or detailed trip purpose definitions.

## Review Status

The trip classifications and travel characteristics presented here are part
of the ongoing SELATRAM v10 model-development process and are provided to
support technical review with NORPC.

Replica and SELATRAM do not define every travel activity in the same way.
The classifications therefore use available trip, activity, traveler,
household, and location information to identify the closest supported
model-facing trip type. Combined classifications are also provided where the
available Replica evidence does not consistently support finer distinctions.

## Project Context

This analysis supports development of the updated NORPC regional travel
demand model. The trip classification methodology follows the general trip
type structure used in the Triangle Regional Model Generation 2 (TRMG2),
including tour context, home-based status, activity purpose, and activity
duration where applicable.

Replica provides modeled travel estimates for a synthetic population rather
than direct household travel survey observations. The resulting trip
characteristics are being used as travel pattern benchmarks to support model
development, calibration, and review.
